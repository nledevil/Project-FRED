MyRobotLab handoff

Release hardware to MyRobotLab hand off servos, audio & camera

When ON, this app drops the I2C servo bus (PCA9685), the USB audio card, and the Pi camera so MyRobotLab (port 8888) can drive them instead — only one stack may own the hardware at a time. FRED's own servo, voice, and camera controls are disabled until you turn this back off. This is a live switch (applies immediately, no Save needed) and the choice persists across reboots.

Needs the Vosk model + a microphone. Open-ended questions also need an Anthropic API key in config/secrets.env — built-in commands work without one. Raise the lead-in (≈0.4–0.6 s) if the speaker clips the first word or two while it wakes up; leave it at 0 for a device that starts instantly.

Lip-sync trim nudges the jaw against the voice. The lead-in is already compensated exactly, so this only corrects what's left — ALSA buffering and the servo's own travel time. Positive if the mouth moves before you hear him, negative if it lags. ±0.2 s is usually plenty; applied live, so tweak it while he's talking.

The mic's analog gain is already maxed, so Mic sensitivity boosts the signal in software. 1× is off; try ≈2× for quiet or distant speech. Past ≈3× it mostly amplifies room noise and clips loud words, which hurts recognition — applied live, no reboot needed.

Terminator clips

When terminator mode is engaged (red LED), FRED plays one of these at random instead of a synthesized catchphrase. Short clips (one line each) work best. Any common audio format is converted to WAV automatically.

Claude terminalbrowser shell on the robot

Opens a full terminal (ttyd + tmux) in a new tab — run claude, git, tests, etc. to work on FRED without SSH. Log in as inmoov with the password from setup; type claude to start. Your session persists in tmux if you close the tab. LAN-only — do not forward port 7681 to the internet.
