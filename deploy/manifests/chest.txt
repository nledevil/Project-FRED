# --- the tool that flashes the sensor node ----------------------------------
# push.py is a stdlib stand-in for `mpremote cp` — it exists precisely because
# this Pi cannot pip install one, and the Pico it flashes is plugged in here.
#
# The firmware itself is deliberately NOT shipped. This directory is flattened,
# and `main.py` is far too generic a name to drop beside the animations — and
# `push.py --target` defaults to the *local* basename, so renaming it would
# quietly flash the board under the wrong name and stop MicroPython running it
# at boot. Copy it over at flash time instead, which is a rare operation:
#
#   scp firmware/pico_sensor_node/main.py dietpi@10.0.0.11:/tmp/
#   ssh dietpi@10.0.0.11 'sudo systemctl stop inmoov-display &&
#       cd ~/display && python3 push.py /tmp/main.py &&
#       sudo systemctl start inmoov-display'
firmware/pico_sensor_node/push.py
